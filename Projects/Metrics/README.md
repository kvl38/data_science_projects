# Моделирование удоев и качества молока

## Описание проекта

Фермер заключил контракт с ассоциацией пастбищ для расширения поголовья. Ему необходимо выбрать коров, каждая из которых будет давать не менее 6000 кг молока в год и при этом производить молоко, соответствующее строгим вкусовым требованиям.

## Цель

Разработать две модели машинного обучения:
- для прогнозирования объёма годового удоя,
- для оценки вероятности получения вкусного молока.

## Используемый стек

- Python 3.x  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- Feature Engineering
- LinearRegression, LogisticRegression 
- Confusion Matrix
- Метрики качества: MAE, RMSE, R2, Precision, Recall
