# Прогнозирование продаж игр для интернет-магазина

## Описание проекта

Проект выполнен для интернет-магазина. Анализируется история продаж компьютерных игр, пользовательские и экспертные оценки, жанры и платформы игр с целью выявить закономерности, определяющие коммерческий успех продукта.

## Цель

Определить ключевые факторы, влияющие на успешность компьютерных игр на глобальном рынке, и сформировать стратегию продвижения перспективных проектов.

## Используемый стек

- Python 3.x  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scipy
