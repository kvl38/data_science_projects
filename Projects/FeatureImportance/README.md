# Прогнозирование снижения покупательской активности

## Описание проекта

Интернет-магазин «В один клик», специализирующийся на продаже широкого ассортимента товаров, столкнулся со снижением активности постоянных клиентов.  
Традиционные методы привлечения новых покупателей уже не дают желаемого результата. Компания решила сфокусироваться на **удержании текущих клиентов** с помощью **персонализированных предложений**, основанных на анализе их покупательского поведения.

## Цель

Создать модель, прогнозирующую снижение покупательской активности клиентов, и на её основе разработать стратегию персонализированных маркетинговых предложений на ближайшие три месяца.

- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- LogisticRegression, SVC, KNeighborsClassifier
- Pipeline, GridSearchCV
