# Прогнозирование заказов такси

## Описание проекта

Компания такси собрала исторические данные о заказах такси в аэропортах.  
Чтобы привлекать больше водителей в периоды пиковой нагрузки, необходимо спрогнозировать количество заказов на следующий час.
## Цель

Построить модель, которая сможет точно предсказывать количество заказов такси на ближайший час на основе временных и календарных признаков.

## Используемый стек

- Python 3.x  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- LightGBM, CatBoostRegressor, RandomForestRegressor  
- TimeSeriesSplit
- Statsmodels
