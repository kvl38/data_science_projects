# Классификация токсичных комментариев для интернет-магазина

## Описание проекта

Интернет-магазин запускает новый сервис: пользователи могут редактировать и комментировать описания товаров. Чтобы защитить сообщество от неконструктивных обсуждений, необходимо автоматизировать процесс модерации.

## Цель

Разработать модель машинного обучения, которая классифицирует пользовательские комментарии как **токсичные** или **нетоксичные**.

## Используемый стек

- Python 3.x
- Pandas, NumPy
- Scikit-learn
- NLTK
- CatBoost, LightGBM
- Transformers (HuggingFace)
