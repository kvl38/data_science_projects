# Определение стоимости автомобилей

## Описание проекта

Сервис по продаже автомобилей с пробегом разрабатывает приложение, позволяющее пользователям быстро узнать рыночную стоимость своего автомобиля.  

## Цель

Построить модель машинного обучения, которая будет точно и быстро определять рыночную стоимость автомобиля на основе его характеристик.

## Используемый стек

- Python 3.x  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- Phik
- RandomForestRegressor, LightGBM, CatBoostRegressor 
- GridSearchCV
