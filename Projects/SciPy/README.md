# Статистический анализ данных поездок сервиса аренды самокатов

## Описание проекта

В распоряжении находятся данные сервиса аренды самокатов GoFast — информация о пользователях из нескольких городов и их поездках.  
Необходимо провести статистический анализ, чтобы выявить факторы, влияющие на выручку компании и привлечение новых пользователей.

## Цель

Провести статистический анализ пользовательских данных и данных о поездках для проверки бизнес-гипотез, влияющих на выручку и пользовательский опыт.

## Используемый стек

- Python 3.x  
- Pandas, NumPy  
- Matplotlib
- SciPy
