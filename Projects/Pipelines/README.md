# Прогнозирование удовлетворенности и оттока персонала в HR-аналитике компании «Работа с заботой»

## Описание проекта

HR-аналитики компании исследуют данные о сотрудниках, включая уровень удовлетворенности работой (по шкале от 0 до 1), чтобы своевременно выявлять сотрудников с высоким риском увольнения. Это помогает сократить финансовые потери от оттока персонала, особенно среди ключевых специалистов.

## Цель

Разработать и внедрить систему предиктивной аналитики для оценки уровня удовлетворенности сотрудников и прогнозирования вероятности их увольнения с использованием методов машинного обучения.

## Используемый стек

- Python 3.x  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- LogisticRegression, KNeighborsClassifier, DecisionTreeClassifier  
- Pipeline  
- GridSearchCV  
- SMAPE, ROC-AUC
