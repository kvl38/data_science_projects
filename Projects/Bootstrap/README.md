# Выбор региона для добычи нефти

## Описание проекта

Добывающая компания планирует бурение новой нефтяной скважины. Необходимо определить наиболее перспективный регион для инвестиций.  

## Цель

Построить модель машинного обучения для прогнозирования объёмов нефти в месторождениях и определить регион с наибольшим потенциалом прибыли при минимальных рисках.

## Используемый стек

- Python 3.x  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  
- Bootstrap
